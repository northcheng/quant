### D / F / G / K 四族的本质区别

同为"挖因子"，三代思路完全不同：

- **D_ = 经典基线（Derived）**。全部由 OHLCV 一阶信息直接构造（`pct_change` / rolling 均值方差 /
  量比），公式最简、文献最老（动量、反转、低波动、均线距离……）。作用是给后续轮次当**基线锚**：
  之后每个新因子都要回答"比 D_mom250 强在哪"。
  构成：动量 6 + 反转 3 + 波动 3 + 波动调整动量 3 + 均线距离 3 + 回撤 1 + 量能 2 + ATR 1 + 偏度 1 = 23。
  验证口径：etf_3x 单池 screen + validate，无 NW/FDR。
- **F_ = 结构升级（Factor）**。从"端点涨幅"（一阶）转向"路径与结构"（二阶）：趋势效率
  （ER / 回归 R² / 斜率 t）、隔夜-日内分解、波动微观结构（下行占比 / vol-of-vol / Ulcer）、
  流动性（Amihud）、K 线形态、池内相对强弱、动量变体。脚本内按 **A~G 七个子族**组织代码
  （A 趋势效率 9 / B 隔夜日内 5 / C 波动结构 7 / D 流动性量能 6 / E 价格形态 5 / F 相对池 4 /
  G 动量变体 3 = 39）；A~G 只是代码分节标签，不出现在因子名中，因子名统一带 F_ 前缀。
  验证口径：复用 signal_search 的 screen/validate，**单池无 FDR**。
- **G_ = 维度扩展**。前三轮吃干经典与结构维度后，专攻**前三轮未覆盖**的文献维度（每因子带出处）：
  波动微观结构 4（Parkinson 比 / 隔夜日内波动比 / 半方差占比 / 极值不对称）、时序结构 5
  （个体自相关 / 方差比 VR / 跳空回补 / 个性化时序动量）、量能不对称 6、路径时间形态 3
  （距新高天数 / Donchian 邻近度 / choppiness）、风险结构 3（下行 β / coskew / 池相关）、
  季节性 2（Heston-Sadka）、组合 3。池组合首次用**美股三池 etf_3x + company_300 +
  company_1000**（无 hs300 / a_etf_all）；统计口径完全复用 alpha 轮
  （NW-HAC + BH-FDR + classify_alpha 分级），结果与第三轮直接可比。
- **K_ = 条件化（Konditional）**。第五轮唯一一轮「不造新裸因子」：把动量强度（mom60 /
  mom121）与个股质量门控（低波 / 量比 / ER / Amihud 的因果历史分位）、池 regime 门控
  （±1 时序 gate）、多周期 sign 共振、强度×质量交叉（秩乘积）做**乘法交互**。设计逻辑：
  单因子弱 ≠ 条件化后弱（excess 的非线性来源）；每池带 F_mom60/F_mom121 裸动量锚
  同口径对照，门控因子与锚的差 = 条件化边际贡献。四子族：个股门控 8 + 池 regime 门控 4
  + 多周期共振 5 + 交叉 2；评估口径与 G_ 轮完全一致，结果直接可比。

## 0. 统一口径（所有轮次一致，无前视）

- **可交易口径**：信号日 t 收盘已知信号值 → t+1 开盘入场 → 持有 h 日 → t+1+h 开盘出场；
  前瞻收益 = Open[t+1+h]/Open[t+1] − 1
- **超额**：excess_k = top5 均值 − 同池等权（long-only 的真实超额来源，非多空价差）
- **显著性**：日级超额序列 → Newey-West HAC（lag = h−1）→ 族内 Benjamini-Hochberg FDR
- **tier 分级**（`alpha_mining.classify_alpha`，score = 0.30·cons_ratio + 0.25·min(exc_min/0.02,1)
  + 0.15·分半同号率 + 0.15·max(0,1−q_max/0.25) + 0.15·(dyn>0)）：
  - **S静态身份**：sig_ac1 ≥ 0.99（截面排序几乎不变 ⇒ 固定选票），score=0
  - **A强**：四池全同号 且 exc_min≥0.005 且 exc_mean≥0.015 且 q_max≤0.10 且分半全同号且 dyn>0
  - **B中**：q_max≤0.25 且（全同号+exc_min≥0.001+exc_mean≥0.005，或 cons≥0.75+exc_min≥0.005+exc_mean≥0.010）
  - **C弱**：cons≥0.5 且 exc_mean≥0.002；**D无效**：其余
- **alpha 化构造**（H_ 族）：`nc(|x|, 252, 60)` = 指标绝对值的 252 日因果标准化分位
  （原型 `m_trend_score_alpha`，与 bc_technical_analysis day 口径一致）

- **长周期双保守效应**：NW-HAC lag=59 压 t + BH 多重检验阈值，h60 级别需 |t|≈3.1+ 才过硬门槛。
- **alpha 化（分位化）不是万能药**：对弱指标无拯救作用；对 trendmag/ichimoku/er 有效。
- **构造方式的边际差异可决定 tier**（K_ 轮）：同素材 mom121×er20——加法组合 C_tmqmom
  C 弱、z 乘积 K_tmq_z 跨池不稳、**秩乘积 K_tmqr B 中**；门控亦同（F_mom121 S →
  K_121_lowvol C）。第六轮起构造方式优先于新素材。
- **口径分歧（B3 实锤）**：统计口径显著 ≠ 交易口径赚钱——H_trendmag_alpha IC 层
  全场唯一 FDR≤0.05，回测 IS 三池全负；K_tmqr 五轮首个 B 中，回测与 C_tmqmom
  ρ≥0.94 同构且略弱。**统计口径筛出的候选必须过 score_backtest 复验才能上线**。
- **组合层增益的结构性证据**（B3）：正交过滤器（G_vr20，与主信号 ρ≤0.26）+ 主信号
  是比同族叠加更优的组合结构——c1000 OOS 1.50 明显超最强单信号 1.26；而 C_tmqmom+K_tmqr
  类同族叠加（ρ 0.94）无增益。附录 B 类第 3 条判断得到验证。
- **文献因子的「池×期限」错配**（A_ 轮实锤）：残差动量（Blitz 等）在 etf_3x 仅
  h60 有效、在个股池仅 h5/h20 有效——三池同号筛选强制取交集（121d 长窗），而交集
  恰在个股池最弱（A 股个股动量周期短、美股 12-1 动量失效），导致本轮零 B 级。
  海外文献因子落地必须过三池×三期限矩阵，单口径显著性（c300 resmom20 h5
  q=0.006）不可外推；信息离散度（Da 等）三池全灭——异象本土化失败 +1（见 §8.4）。
